# FI-2010 Execution-Aware Proxy Diagnostic V3

This is an offline execution-aware proxy diagnostic. It is not a live trading system, broker integration, profitability claim or realistic execution simulator.

- Payoff mode: `unit_payoff`.
- Cost mode: `unit_proxy`.
- Reported cost-adjusted values are proxy diagnostics, not PnL.
- Stationary predictions are no-trade signals in trade-specific metrics.
- Costs are subtracted from active or filled directional trades only.
- Inputs were not marked as smoke-test artefacts.

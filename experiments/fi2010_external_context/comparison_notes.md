# FI-2010 External Context Artefact

This directory stores a small protocol-comparison artefact for FI-2010 external
benchmark context.

Files:

- `benchmark_context.json` records the ChronosLOB protocol snapshot, current
  local result snapshot and external references without external numeric
  metrics.
- `protocol_comparison.csv` lists protocol dimensions and caveats for local and
  external sources.
- `comparison_notes.md` is this note.

Boundaries:

- no model was run to create this artefact;
- no prediction rows or checkpoints are written here;
- no SSL result is reported;
- external papers are included for protocol context only until exact source
  metrics are verified and matched to ChronosLOB's protocol dimensions.

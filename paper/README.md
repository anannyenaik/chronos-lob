# ChronosLOB Research Paper

This directory contains the full research-paper draft for ChronosLOB.

**Paper:** [`ChronosLOB.pdf`](ChronosLOB.pdf)

The paper presents ChronosLOB as a leakage-safe market-microstructure forecasting platform with FI-2010 benchmarks, supervised and self-supervised neural experiments, replay extensions, feature-stability analysis and execution-aware diagnostic evaluation.
